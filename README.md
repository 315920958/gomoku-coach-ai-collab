# gomoku-coach-ai-collab

> gomoku-coach 项目的 **AI 协作文档仓**。
> 这里不写代码，只做两件事：**定人和 AI 怎么沟通的规矩**，以及**从高处把整个项目长什么样描述清楚**。

## 这仓是什么

- **角色**：本仓是「规范 + 通讯」层，不是代码项目。
- **归属**：gomoku-coach 系统的一个子仓，专门服务于「人 ↔ AI」协作。
- **关联代码仓**：`gomoku-coach-engine`（当前唯一的代码项目，解说引擎）。

## 目录导航

| 目录 | 作用 |
|---|---|
| `spec/` | 总体级文档：项目结构总览、术语表、人-AI 对话规范 |
| `plans/` | 开发计划（按阶段拆文件） |
| `decisions/` | 决策记录（重要决定留痕，带模板） |
| `handoffs/` | 对话交接文档（过阶段开新对话前的交接，带模板） |
| `scripts/` | 脚本文件夹（协作 / 工具类脚本，将来大量扩充） |

## 快速初始化（AI 自动补齐代码工程）

把本仓 clone 下来后，AI 可据 `spec/04-初始化与代码工程拉取.md` 自动补齐清单里的**所有代码工程**、统一切到 `develop` 分支并 `git pull`。新增代码工程只需往该文档的清单表格加一行，AI 启动时只认那张表。

## 怎么用这仓

1. 新开一段对话前，先读 `handoffs/` 里最近一篇，接上前情。
2. 要定规矩 / 改结构，先写（或更新）`spec/` 下的文档。
3. 做了重要决定，往 `decisions/` 补一篇。
4. 一段对话收尾，往 `handoffs/` 写一篇，供下一段接力。
