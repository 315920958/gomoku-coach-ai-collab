# 开发计划

> gomoku-coach 系统的整体开发路线。代码细节见 `gomoku-coach-engine` 自身的开发计划。

## 阶段总览

| 阶段 | 内容 | 状态 |
|---|---|---|
| 阶段 0 | 初始化对齐：定协作规范、项目结构、命名 | 进行中（本对话） |
| 阶段 1 | 确定拉菲 CLI 调用方式，建立首批编号案例 | 进行中（第一波：[mac 调通本地拉菲](./2026-08-23-mac调通本地拉菲.md)） |
| 阶段 2 | 人工讲解反向提炼：探索硬性指标与讲解分支 | 未开始 |
| 阶段 3 | Node.js 固化已验证指标，接入总入口 / 分支 skill 两次调用 | 未开始 |
| 阶段 4 | 基于编号案例回放、评测和迭代 | 未开始 |
| 未来 | 表现层（前端）/ 后端（按需） | 规划中 |

## 说明

- 阶段 0 的产物即本 `gomoku-coach-ai-collab` 仓的骨架与各规范文档。
- 阶段 1–4 的主体在 `gomoku-coach-engine` 代码仓，本仓只跟踪进度与决策。
- 每个阶段可在 `plans/` 下拆独立文件，重大节点在 `decisions/` 留痕。
